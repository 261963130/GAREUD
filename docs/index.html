Ground-Aerial RGB--Event UAV Dataset

Aligned RGB--Event UAV detection from precise sensing to edge evaluation

A real-world and synthetic benchmark for small-target UAV detection, multimodal fusion, cross-modal alignment, and edge-oriented evaluation.

Download GAREUD-Real GitHub

Overview

RGB--Event UAV data for realistic and controlled evaluation

Precise RGB--Event Sensing

GAREUD-Real uses co-axial imaging and microsecond-level trigger synchronization to reduce spatial parallax and establish exposure-level temporal pairing.

Real and Synthetic Subsets

Real-world recordings preserve natural sensing effects, while synthetic data provide native correspondence for controlled perturbation analysis.

Edge-Oriented Benchmark

The dataset supports evaluation of lightweight RGB--Event detection pipelines under ground-to-air and air-to-air acquisition conditions.

Structure

Sequence-level RGB, event, label, and synchronization files

GAREUD-Real

Each real-world sequence is stored as GAREUD_R/GAREUD_R_xxxxxx/ with RGB frames in rgbframe/, one raw event-stream HDF5 file, calibration and synchronization information, and labels.txt.

GAREUD-Sim

Each synthetic sequence is stored as GAREUD_S/GAREUD_S_xxxxxx/ with RGB frames in images/, event-frame representations in event_frames/, raw events in events.h5, and labels.txt.

Labels

Real-world labels use timestamp class_id x_center y_center width height. Synthetic labels use frame_id class_id x_center y_center width height. Bounding boxes are normalized.
